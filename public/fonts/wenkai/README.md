LXGW WenKai Regular v1.250, distributed by `lxgw-wenkai-webfont@1.7.0`.

- Font license: [SIL OFL 1.1](OFL.txt). Webfont packaging license: [MIT](WEBFONT-LICENSE.txt).

The 97 original Regular WOFF2 slices (4,634,808 bytes in total) and their
`unicode-range` stylesheet are copied without modifying font data or names.
Only slices used by the visible text are fetched. No external font CDN is used
at runtime. `font-display: swap` keeps text visible while loading; an unavailable
character or file falls back to the reading font stack. Use only weight 400 for
this face, with synthetic bold disabled in CSS.

This is the original Regular edition, not the Screen edition (whose upstream
documents a possible macOS blur issue). It is a design choice for 留白, not a
claim about the font used by NetEase Cloud Music.
