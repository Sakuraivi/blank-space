# 留白 · 生活片刻整理 v0.1

面向朋友与同事首轮试用的手机网页原型：一件生活小事 → 一个关注点 → 可跳过的原创卡牌 → 最多三个问题 → 编辑确认 → 保存或导出。

源码仓库：https://github.com/Sakuraivi/blank-space

体验地址：https://liubai-little-moments-sakura.zhengjuzhong3.chatgpt.site

## 使用边界

- 这是一套固定问题的交互原型，不调用运行时生成模型，不提供心理诊断或占卜预测。
- 三类入口：开心时刻、心事、小选择。六张原创 SVG 卡牌仅提供图像联想。
- 复盘草稿逐项引用用户输入，由用户修改、删除、标记不确定并确认。
- 页面不录音；手机可使用键盘自带语音输入，音频处理取决于设备与输入法。
- 输入在浏览器中处理。进行中的内容只在内存，刷新或结束会清除。
- 主动保存仅把确认后的记录写入此浏览器的 localStorage；原始回答不随之保存。最多 30 份，可逐条删除。
- 支持确认后 PNG 和 TXT 下载；反馈 JSON 单独下载，不自动附带复盘正文，不自动上传。
- 站点托管可能有常规访问日志。本应用没有正文上传、第三方字体、外部脚本或自动埋点。

## 本地运行

在此目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后打开 http://127.0.0.1:4173/ 。ES Modules 需要 HTTP 服务，不要直接双击 index.html。

```powershell
node --check dist/app.mjs
node --test core.test.mjs
```

无需依赖安装和构建。dist/ 可部署到静态网站托管。

## 公开访问与独立部署

- 应用源码没有登录、OAuth、ChatGPT SDK 或 API Key 依赖，访问和完整体验均不需要 ChatGPT 账号。
- 将 `dist/` 设为站点发布目录即可。没有构建命令、服务端函数或必需的环境变量。
- 使用 HTTPS；服务器应将 `.mjs` 以 JavaScript MIME 类型提供。页面和素材使用相对路径，支持部署到子路径。
- 托管平台如有访问密码、预览保护或登录限制，应在平台侧关闭。这些设置不属于应用源码。
- `.openai/hosting.json` 仅用于关联现有 Sites 项目；其他静态托管平台无需读取它。不要把仓库根目录作为发布目录。
- 当前体验站点的访问受众已设为公开，允许匿名访问。公开的是网页；记录仍仅保存在体验者主动保存时使用的浏览器中。
- 更换域名不会迁移浏览器中的旧记录；需要保留的内容请先从原地址导出。

## 首轮测试

邀请 3–5 位愿意体验的成年人，每人约 15 分钟。先用轻量话题；允许私下操作，只反馈流程而不交出私密内容。若由主持人代替软件读脚本，明确告知这是人工试跑。

观察：入口是否清楚；哪一步想跳过；卡牌是否帮助开口；总结是否忠实；是否愿意在另一天主动再用。不要把礼貌好评当作效果证据。

结束后可使用页面反馈表。反馈由体验者自行决定是否提供给组织者。当前没有自动收集反馈的服务器。

## 文件

- dist/index.html、style.css：结构与响应式界面。
- dist/app.mjs：交互、编辑、本机记录、导出与反馈。
- dist/core.mjs：问题、卡牌元数据、原话归档、保存校验、离开提醒规则。
- dist/assets/：六张原创生活场景 SVG。
- core.test.mjs：针对数据边界和已发现缺陷的回归测试。
- DESIGN.md：已采用的设计与数据约束。
- QA.md：本轮验证记录与限制。
