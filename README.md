# 留白 · 生活片刻整理

从一件生活小事开始，经关注点、可选生活图像卡和最多三个问题，留下一份自己修改并确认的记录。默认保留本地记录；可选 AI 试用由站点管理员统一承担 DeepSeek API 费用，朋友使用体验码进入。

## 两种体验与数据边界

- 本地模式：固定问题、原话整理；不向模型发送正文。
- AI 模式：首页单独选择，填写测试组织者提供的体验码，并同意将本次故事、焦点、卡片联想、实际问答及纠正，经留白后台发送给 DeepSeek。不会自动上传旧记录。
- AI 每次最多提供一个问题；理解是可纠正的候选，不能作心理诊断或占卜。最多三个实际问题，可跳过、提前整理或结束；失败保留输入并支持原话回退。
- 进行中的表达和体验码只在页面内存中；刷新或结束清除本页内容，不能撤回已发送给服务商的文字。服务商的数据处理规则适用于 AI 请求。
- 主动保存只将确认后的记录写入此浏览器的 localStorage，最多 30 份；不另存原始问答、纠正轨迹、模型响应或凭据。支持逐条删除、PNG/TXT 导出。
- 反馈 JSON 单独下载，不自动附带复盘正文，不自动上传。页面不录音；键盘语音输入由设备与输入法处理。
- 应用 D1 只保存加密配置和调用账本，不保存复盘正文；账本含请求摘要、状态、版本和用量。托管及供应商仍可能处理必要的访问、用量和错误信息。

## 首批 API 额度

首家服务商已确定为 **DeepSeek**，固定模型 `deepseek-flash`，非思考 JSON 模式。用户同意的测试总预算为 **人民币 1 元以内**。

| 约束 | 当前实现 |
| --- | --- |
| 每次保守占用 | ¥0.05，使用整数微单位记录 |
| 全批调用上限 | 18 次，共预留 ¥0.90，保留 ¥0.10 余量 |
| 每会话 / 同时进行 | 最多 5 次 / 最多 2 次；全局 18 次仍为总门槛 |

| 价格复核期限 | 北京时间 2026-11-06 00:00 到期停用，需复核后再启用 |

这些是应用侧保守预留和停止规则，**不是已经发生的费用，也不是供应商账单保证**。价格、token 统计及预算假设仍需真实小样本核验。更换 Key、关闭或重新启用均不重置本批账本。

## 管理员配置

管理页源文件为 `public/admin.html`，部署后路径为 `/admin.html`。页面依赖 Sites 提供的登录身份，仅已授权管理员可读写配置；体验者使用本地流程和体验码，不需要登录 ChatGPT。

后台需先具备 D1 `DB` 绑定和托管秘密配置：

- `LIUBAI_SECRET_KEY`：32 字节随机值的 Base64 编码，用于 AES-GCM 加密 Key。只放服务端秘密配置。
- `LIUBAI_BOOTSTRAP_EMAIL`：首次绑定管理员的站点所有者邮箱；绑定后使用站点范围的稳定用户 ID 授权。

管理员在页面填写 DeepSeek Key、8–64 位字母/数字/连字符组成的体验码，选择是否启用并保存。Key 加密保存在 D1，不返回浏览器；体验码只保存摘要。保存本身不调用模型，也不代表连接验证成功。删除 Key 会同时关闭 AI，但保留已用额度。

生产身份头必须来自 Sites dispatch；不能将该授权方式原样作为普通、可直连的 Worker 服务部署。不要将真实 Key、加密主密钥或体验码提交到 Git、前端资源或聊天中。

## 运行与检查

需要 Node.js 22.13+；本轮自动化使用 Node 24。当前为 Vinext / Cloudflare Workers 项目，`public/` 是手写前端源码，`dist/` 是构建输出，不能再把旧 `dist/` 当作源码编辑。

```powershell
npm run install:ci
npm run dev
```

使用终端实际输出的本地地址；portable 配置默认端口为 5173。完整 API 依赖 D1 表和服务端环境；未配置时 AI 保持不可用，本地记录仍可使用。数据库结构在 `db/schema.ts`，迁移在 `drizzle/`。

```powershell
node --check public/app.mjs
node --check public/core.mjs
node --test core.test.mjs public-flow.test.mjs ai/*.test.mjs server/*.test.mjs
npm run build
```

2026-10-30 当前全量自动化 **78/78 通过**；均使用假凭据、假供应商响应和测试数据库，不产生模型费用。本次最终构建已通过；浏览器完成 mock 对话、失败回退、取消/迟到响应和本地管理员边界检查。生产发布状态见 [QA.md](QA.md)。

若只查看本地记录界面，可用静态服务器服务 `public/`；它不提供 AI 后台或管理员接口：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory public
```

## 目录

- `public/`：生活记录界面、管理员页面、样式和卡片素材。
- `app/`、`worker/`：Vinext 路由与 Worker 入口；同源 API 转交 `server/api.mjs`。
- `ai/`：场景提示词、上下文/候选契约、DeepSeek 适配器、取消/超时处理、持久账本接口及测试。
- `server/`：授权、配置、加密和调用路由；不保存私人复盘正文。
- `db/`、`drizzle/`：D1 表定义与迁移。
- `.openai/hosting.json`：保留现有 Sites 项目 ID，声明 D1 `DB`；运行秘密不放在此文件。
- `openspec/changes/ai-api-pilot/`：[提案](openspec/changes/ai-api-pilot/proposal.md)、[设计](openspec/changes/ai-api-pilot/design.md)与[待办](openspec/changes/ai-api-pilot/tasks.md)。
