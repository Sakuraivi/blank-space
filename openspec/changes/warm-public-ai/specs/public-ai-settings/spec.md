## Purpose

让留白访客无需账号验证即可选择本次 AI 体验使用的 DeepSeek 凭据：有个人 Key 时优先使用个人 Key，留空时使用组织者提供的默认 Key。此能力同时限定秘密的生命周期、共享配置权限、明确的传输选择和小额测试批次的统一停止规则。

## ADDED Requirements

### Requirement: 公开可发现的个人设置
系统 SHALL 在公开页面提供可发现的 AI 设置入口；访问和填写个人设置不要求 ChatGPT 登录、其他账号登录或体验码。设置页不得向访客授予全站默认凭据的读取或修改权限。

#### Scenario: 匿名访客打开设置
- **WHEN** 未登录访客从首页或旧管理页地址进入 AI 设置
- **THEN** 系统显示个人 Key 的可选输入与默认凭据可用状态，不显示必须登录的门槛

#### Scenario: 尝试修改全站默认凭据
- **WHEN** 匿名访客直接调用原全局配置读写接口
- **THEN** 系统拒绝操作，不返回秘密值，也不改变默认凭据

### Requirement: 个人凭据优先且失败不切换付费来源
系统 SHALL 优先使用访客本次提供的非空个人 Key；个人 Key 留空时才使用服务端默认 Key。无默认 Key 时，系统须允许访客填入个人 Key后继续；两者均缺失时不得发送模型请求。非空个人 Key 格式不合法或供应商拒绝认证时，系统不得静默改用默认 Key。

#### Scenario: 个人 Key 与默认 Key 同时存在
- **WHEN** 访客提交非空、格式合法的个人 Key 并主动开始 AI 请求
- **THEN** 该请求仅使用个人 Key，界面说明本次使用个人凭据

#### Scenario: 留空使用默认凭据
- **WHEN** 访客未提供个人 Key且默认 Key 可用
- **THEN** 请求使用默认 Key，界面说明本次由组织者提供体验额度

#### Scenario: 个人 Key 无效
- **WHEN** 个人 Key 非空但格式不合法或上游拒绝其认证
- **THEN** 系统返回可理解的配置或回退提示，不调用默认凭据重试

### Requirement: 个人 Key 仅属于当前页面体验
系统 SHALL 只在当前页面内存和处理该次请求的服务端内存中持有个人 Key；不得写入 localStorage、sessionStorage、Cookie、URL、导出记录、数据库、日志、模型提示词或错误响应。访客清除个人设置或离开当前页面后，不得从应用持久状态恢复该 Key。

#### Scenario: 刷新或导出记录
- **WHEN** 访客刷新页面，或保存/导出已确认的记录
- **THEN** 页面刷新后个人 Key 为空，保存和导出的记录不含个人 Key

#### Scenario: 服务端处理个人凭据
- **WHEN** 后台收到个人 Key 并准备发送给固定 DeepSeek 服务
- **THEN** Key 仅用于该请求的供应商认证，不成为模型可见材料或持久账本内容

### Requirement: 配置不触发模型消费
系统 SHALL 将设置保留、凭据选择与实际推理分开。打开设置、填写或清除 Key、读取可用状态，不得触发模型调用；只有访客明确同意本次材料发送并发起 AI 流程后才可调用。

#### Scenario: 仅填写个人 Key
- **WHEN** 访客填写 Key 并关闭设置，尚未选择同意发送
- **THEN** 系统不预留模型调用、不发送正文，也不宣称连接已通过

### Requirement: 所有凭据共享同一规则和测试停止条件
系统 SHALL 对个人与默认凭据应用相同的平台场景指令、候选结构及来源校验、请求与输出上限、超时和迟到响应丢弃规则。本轮所有来源共同受持久总计 18 次、每会话 5 次、同时 2 次限制；调用前按每次 ¥0.05 保守预留，换 Key 或来源不得重置账本。北京时间 2026-11-06 00:00 到期后拒绝新调用。

#### Scenario: 改用个人 Key 后批次已经用尽
- **WHEN** 同一批 18 次资格已消耗，访客输入或更换个人 Key
- **THEN** 系统仍拒绝新调用并保留本地整理流程

#### Scenario: 上游失败或取消
- **WHEN** 可能计费的请求发出后超时、取消或输出无效
- **THEN** 系统保留一次占用、不自动重试，允许用户保留原话继续整理

### Requirement: 保持传输同意与用户确认
系统 SHALL 在 AI 请求前说明本次原话、回答与纠正经留白后台发送给 DeepSeek，不自动上传旧记录；用户材料与平台指令须分开处理。模型输出只作可编辑候选，用户确认后才允许保存记录。

#### Scenario: 访客选择只做本地记录
- **WHEN** 访客未同意 AI 传输或选择本地流程
- **THEN** 系统不向模型发送正文，三场景的本地整理、确认与导出继续可用
