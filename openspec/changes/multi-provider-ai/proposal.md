## Why

留白目前的公开 Key 入口和服务端只支持 DeepSeek。用户明确需要 DeepSeek、Kimi、GLM、OpenAI，希望用统一、简洁的设置接入，并继续获得符合生活复盘场景的内容。

## What Changes

- 增加四家官方服务商及经核对的试用模型白名单；服务商、模型、API Key 在同一设置中明确选择。
- Key 字段统一命名为「API Key」，接收方、模型、费用承担方和发送同意随选择变化；一次体验内锁定配置。
- 服务端路由和传输参数按服务商适配，每次调用继续注入统一场景规则并验证候选内容。
- 保留个人 Key 优先、无个人 Key 时使用明确的组织者默认配置；失败不切换付费方或服务商。凭据不进入故事、提示词或持久存储。
- 保留已有 D1 共享批次和原预算约束；用户已确认默认Key受共享18次及1元预算限制，个人Key自费且不占共享额度，两种来源仍受每会话5次、并发2次与单次请求边界约束。
- **BREAKING**：公开配置及同意版本升级，旧页面须重新加载并确认接收方后使用新版多服务商接口。

## Capabilities

### New Capabilities

- `multi-provider-routing`：官方服务商白名单、模型适配、统一规则、凭据隔离、费用与持久门禁。
- `multi-provider-settings`：公开服务商/模型/API Key 设置、默认来源、同意及会话生命周期。

### Modified Capabilities

无已归档的同名能力；本变更延续此前 warm-public-ai 的公开入口和暖感界面。

## Impact

涉及 `ai/` 传输与模型目录、`server/api.mjs`、公开设置与生命周期、相关测试和说明文档。继续部署既有公开站点及域名，不重置 D1，不增加自定义代理端点，不自动调用用户真实模型。
