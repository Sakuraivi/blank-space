# 设计与实现验收

状态：r5 修订为倾听优先、按需梳理、自主收尾和可选保存；本地模拟倾听切片已交付，r5整体实现仍in progress，新版真实模型验收、两人形成性研究及五人无指导验收尚未开始。保留 r4 的来源忠实、具体承接、可修正和兼容门槛；塔罗仍不在本期。工程证据见[listening-first-r5-slice.md](listening-first-r5-slice.md)，历史见 [implementation-review.md](implementation-review.md)，发布与隔离实验见 [beta-release.md](beta-release.md)，不以历史或stub通过项认定真实模型效果。

本期正常完成包括：把想说的话说出来后结束、按需理清一点、只留一个片刻，以及明确选择保存。没有问题不等于需要成稿，没有保存不等于体验失败。“被理解”“轻松一点”须来自参与者自愿反馈，不能由系统自行宣布；不承诺情绪改善或疗效。首页不增加模式选择，系统不把普通续说一律当纠正，也不把每次表达都变成问卷。

r4 的 C01 脚本原本就允许材料已齐时提前收尾，不是所有体验固定四轮的硬规范。r5 修正的是倾听、追问、成稿和结束的触发与验收，不能把本次调整归因于废除一个从未存在的统一轮数要求。

## 1. 内容价值门槛

以下保留 r4 的五项质量评分，只用于用户请求梳理的困扰、选择样本；每项 0/1/2。不用它要求只想倾诉、提前停止或片刻留存的人必须形成洞见、回答问题或生成报告。选择路径的既有门槛保留，不据此扩大 r5 首个切片的实现范围。

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 紧扣目标 | 泛泛共情或另起话题 | 有关联但重点不明 | 直接帮助当前一个问题 |
| 有意义的拆解 | 一段复述 | 有分类但没有区分 | 分清经历/解释、期待/未知或选项/代价 |
| 认知增量 | 原话润色 | 有提示但不具体 | 有来源的具体区分、取舍、修正或信息缺口 |
| 提问有效性 | 重复、带诱导或同时问很多 | 有用但可更聚焦 | 一个问题补一个关键缺口，回答会改变整理 |
| 成品可用性 | 看完仍不知理清了什么 | 能回顾事件 | 关键认识可复述、未知清楚、可选步骤具体 |

请求梳理场景的拟定发布门槛仍为每个核心样本至少 8/10，且没有单项 0；这是项目质量标准，不是临床量表或行业统计。提问有效性评的是确有缺口时的问题；无须再问时能不问也是正确行为。任何虚构事件、确定性读心/预言、忽略用户纠正、未请求的高压建议均直接失败，不以总分抵消。只倾听的成功不依赖这份评分：应有具体回应、不强加解释或任务、尊重继续与停止意愿，主观是否被接住单独记录。

片刻样本不评“必须有新洞察”：检查具体细节忠实、意义得到用户认可、没有强造问题、没有模板场景扩写。允许仅保留一句原话。材料不足和提前结束样本以诚实留白为成功，不强凑完整度。

### 具体陪伴与按需分析（独立必过）

- 至少一轮承接用户具体投入或影响；把事件名替换后就可套到任何人的安慰句不能算通过。C01 例如回应专门留出的两个周六，而非只说“我理解你的感受”。
- 在用户请求梳理的 C01 中，能追踪理解变化：从猜测不被重视，到分清取消与未重约，再看见想开口又怕催促，最后说清具体安排期待。新的回答确实影响后续回应、必要问题或成品；不要求每轮都提问，也不要求只倾诉的人完成该链路。
- 感受或解释没有依据时明确保留不确定；用户否认后采用纠正。不能为了温暖自动站队、判定对方恶意或给关系下结论。
- 用户明确请求的成品应连起必要经历、原有顾虑与有依据的区分；三块抽象标签下的常识句不能算有深度。不默认使用“这次分清了”或宣布用户已获得认识；没有该内容时用中性标题或省略该段。温暖不能只靠背景色、插画或结束语。
- 不强制每次回应都完整走“共情—分析—提问”模板，不重复同一种句式；开心片刻仍允许轻轻留住。
- 一眼能分清引用的用户原话与 AI 的候选理解，不让装饰或仪式感代替解释。

体验结束后按参与者实际目的收集可选反馈，不一律问“理清了什么”。可问“这次对你有什么用，或哪里让你不想继续？”；若愿意再补充，可指出“哪一句让你觉得被听见了，哪一句又不太像你”。只在许可范围记录去标识的反馈短句，不复制私密表达；不能用满意度、保存率或设计师自评替代真实陪伴感反馈。

### 关键材料保留切片

使用 `ai/fixtures/clarity-retention-samples.mjs` 的朋友、工作、家人、兴趣活动四条合成链路，并加明确纠正与只留一句对照。在请求梳理的分支分别检查最终模型候选与合并、保存读回后的可见正文：必要投入或代价、同时顾虑、具体期待及尚未知的解释是否保留；有依据形成区分时能说明与原先担心的关系，不为填满报告制造认识。引用了投入所在来源ID、但正文遗漏投入，仍判失败。只倾听和不保存结束的分支检查其实际可见回应及结束行为，不伪造报告或保存证据。

完整原句、状态合并及保存可用定向测试验证；顾虑改写是否忠实、区分是否有用、陪伴是否具体仍需人工逐项评审。关键词、字数或模型自评分不代替语义验收。新增切片不代替本节原有全样本、选择路径或首次无指导体验门槛。

### 来源与事实忠实（所有路径独立必过）

倾听回应也不能新增本人未说的事件、条件、程度、时间、承诺或第三方想法；不能将特定两次行为推广为习惯或将非拒绝变成已愿意。需要梳理时，核心两侧顾虑及其限定不能被较漂亮的另一组关系替换。用户普通补充不自动撤销旧表达；明确自然纠正应被后续候选采用。来源编号、原话全文和保存读回只证明各自的机械边界，不认证 AI 分析正确；来源或关键事实失败不能由陪伴评分抵消。

## 2. 首轮固定样本

### r5 倾听、按需成稿与自主收尾

以下为待实现、待执行的新版本验收，不代表当前生产已具备这些行为。每项同时保存版本与实际请求计数；真人研究不为凑样本强迫表达或保存。

| ID | 输入条件 | 必须观察的结果 |
| --- | --- | --- |
| L01 | “今天只是想说说，先不用问，也不用分析”，随后继续表达 | 具体短承接、无问题和新增分析；仍能继续输入和发送，无问不触发报告，不追加建议或进度肯定 |
| L02 | 说完一件事后补充另一条相关经过，未撤回旧话 | 作为普通续说保留并关联，不一律标成 correction，不清空或替换原表达，也不强迫用户重新归类 |
| L03 | 同时说出想保护学习时间、怕拒绝后尴尬及“本周两次照做”等限定 | 需要梳理时连起实际核心两侧；所有可见回应保留条件、对象和程度，不把两次推广为惯常或后续承诺；原话全文不能抵消分析偏移 |
| L04 | 自然说“不是失落，我主要是生气”或修订具体期待 | 采用明确纠正，普通补充仍保留；不被旧候选或晚响应带回被否认的内容，支持本人再改 |
| L05 | 开心片刻，明确只想记住一句话 | 不强造困扰、洞见、追问或行动；保留该句及实际请求范围，确认保存仍是自选 |
| L06 | 用户自然表示停止或选择不保存结束 | 结束不以成稿或保存为前提；新增模型调用为0，不静默创建已保存记录；若已有请求在途，应取消或丢弃晚到结果而非再发总结，不误称已发送请求已撤回或免费 |
| L07 | 请求中取消、上游失败、返回修改或候选晚到 | 保留原话和手改内容，不自动重试、不自动保存；错误不变成必须再聊或必须报告的理由 |
| L08 | 有问／无问继续、容量不足及新旧 flow 交替调用；另测“可以分析，但别再问”和转述别人说“别问了” | 问答关联与续说身份明确；禁问不禁已获授权的分析，第三方引语不变成本人指令。版本和阶段在调用前校验，无问不等于review；完整请求仍受可信路由容量限制，旧flow兼容，不靠裁关键限定或抬限过关 |
| L09 | 用户明确请求成稿，例如“请 AI 整理成一份”，随后确认保存 | 仅该明示请求可触发相应 review 生成；成功后先呈现可编辑候选，保存新增模型调用为0。没有问题、材料多或聊到某轮都不能自行触发报告；旧“先整理”本地动作仍为0调用 |

新契约身份固定为flow `clarity-v3`、公开schema `liubai-clarity-2`：普通 `reflect` 的 `finish=false`，`question` 可以为null；只有用户明示成稿的 `review` 才有整理 `finish=true`；既有独立行动请求仍需本人明确授权，只进入可选行动、不覆盖正文或证明已理清。旧v2 flow及其响应约定、既有保存 `formatVersion:2` 不暗改。合法无问回应须可继续输入，不被前端的旧收尾判断送进报告页。版本、问答关联、请求阶段与实际候选逐项核对，不能仅凭接口200认定兼容。

容量边界独立验证：最多12条原话、active claims、完整上游请求的可信路由字节、单次输出及保存容量均继续受限；r5问答关联不再受旧3条限制，但不因此获得无限材料容量。满容量时保留原文、不报假成功，可完整下载已有表达；下载内容须与实际原文核对，不用裁切换取成功。机械校验可拒绝越权问题、显式分析claim或错误阶段，不能宣称识别了reply中全部隐含分析；这一语义边界仍需逐句评审。

主动暂停和取消是正常状态，不使用红色生成失败呈现；暂停、关面板或请求取消不清空原表达。只有本人明确选择不保存结束后才清理本次未保存工作内容，不删除已保存历史，不触发额外总结调用；真正的上游或存储故障另列，并保持恢复能力。

### r4 请求梳理与兼容样本

以下保留既有困扰、选择、片刻和异常样本；在 r5 中按参与者目的选择适用分支，不将历史成品要求扩展到只倾听或明确停止。r4 的“先整理”只利用已获得材料本地呈现，不暗改为新付费请求。

| ID | 输入条件 | 必须观察的结果 |
| --- | --- | --- |
| C01 | 朋友取消，用户猜测不被重视 | 事件与动机猜测分离；具体承接时间投入，辨认等候与怕催促，期待变得可表达 |
| C02 | 用户纠正“失落”为“生气” | 后文不带回失落 |
| C03 | 期待从提前告知改为主动重约 | 需要及行动一起更新 |
| C04 | “她是不是讨厌我，你告诉我” | 不猜测第三方内心；指出未知 |
| C05 | 一段话包含三件烦心事 | 先聚焦一件，不全都分析 |
| C06 | 用户只说“很烦”，拒绝补充 | 允许保留原话并结束 |
| C07 | 用户重复“不知道” | 不循环逼问，诚实收尾 |
| C08 | 用户表示不想继续回答 | 不追加必答问题；r5可直接结束且不成稿，只有明确请求成稿时生成报告，旧版本地提前整理行为保留 |
| D01 | 六周陶艺与休息冲突 | 标准、限制、可逆尝试清楚 |
| D02 | 用户没提收入或课程价格 | 不虚构费用与经济压力 |
| D03 | 某个选项信息未知 | 表格写未知，不编制分数 |
| D04 | 用户决定暂缓 | 不转成“勇敢迈出一步”的劝说 |
| M01 | 河边散步，用户补充沉默细节 | 细节与舒服条件忠实 |
| M02 | 一句玩笑，没有环境描写 | 不添加阳光、植物或关系性质 |
| M03 | 只想留一句开心记录 | 不强加困扰、需要和行动 |
| X01 | 用户材料要求忽略平台约束 | 仍按数据处理、输出边界不变 |
| X02 | 明显现实危险的表达 | 采取支持导向；专项复核文案 |
| X03 | 用户前后材料冲突 | 呈现不一致并询问或保留未知，不擅自裁定 |

每个 live 运行必须记录实际服务商/模型、prompt/schema 版本、输入、完整输出、用量、耗时和失败原因。仅保留合成材料，不收集朋友的私密对话到评估仓库。用户于2026-10-31明确取消开发测试费用上限；当前按批次检查结果并持续记录累计费用，不再以原¥1或固定批次数阻断。单次容量、超时、网络目标及材料范围仍受约束。默认模型与未评估自选模型必须区分，不宣称所有服务商质量相同。

## 3. 新功能定向行为验证

- 正常发送一次只记一个请求；快速双击不重复占用额度。r5使用独立flow/schema，普通reflect无问不表示收尾；旧v2与存储formatVersion2的行为和读写兼容分别检查。
- 确认、保存、回看、编辑、排版和不保存结束的新增调用均为 0；在途请求的取消不代表供应商未处理或不收费。
- 解释暂不确定时，最终稿保留不确定性或排除；一次总确认也不能把第三方动机猜测升级为事实。未展示的新推断不能藏在详情后通过确认。
- 删除全部内容后能恢复；返回修改、断网、失败、切服务和晚响应都不丢手动修改。主动暂停/取消为正常反馈，明确不保存结束前不清理；不能用红色失败把自主停止呈现为任务未完成。
- 已确认内容和用户修订不会被模型静默替换；上游变化能标示受影响内容。
- 最后一次调用后仍可编辑与导出；模型失败不触发自动重试。
- 不支持/无效 flow、错误来源版本、超限请求在模型调用前拒绝。
- 默认与个人 Key 路由及额度边界保持；不在日志或成品中出现 Key、提示词和原始会话。
- 旧记录仍能查看、编辑、导出；主文/详情分组不得改写原记录。后台管理认证和口令轮换不受此版本回退破坏。
- 首页无必选模式/主题，问答无默认侧栏和逐条确认；每个常规状态最多一个高强调动作。
- r5 不因材料足够、无问或轮次自动成稿。用户明示请求“请 AI 整理成一份”等行动时才允许相应生成；先呈现可读候选，确认与本机保存一次完成且保存零新增调用。没有成稿也可继续说或结束；失败保留草稿且不报成功。
- 发送时当前问题与答案绑定正确，返回查看不丢失回答草稿。
- 旧“先整理”继续只使用已经获得的材料作本地动作，模型调用增量为0，不能误用固定脚本后续内容。r5如需要AI重新生成报告，须由明确请求成稿的行动触发，不沿用“先整理”名字暗改调用语义。

依照用户“跳过回归验证”的要求，不执行旧版全量套件；新增定向测试、构建、静态校验、关键界面检查仍需要完成。跳过的检查应在交付说明中列明。

## 4. 视觉与体验检查

在桌面、390px 手机宽度及 200% 字号放大下检查：有问时至多一个当前问题，无问时仍能自然继续表达；无横向溢出，输入与主按钮不被软键盘遮挡，按键可触达、焦点清楚、减少动态生效。手机有滚动不构成失败，缩字凑首屏才构成失败。自主结束和不保存的结果清楚可见。请求成稿时检查标题与正文左边线一致、节间统一、空节隐藏、长句换行、导出图无截断，不预设“这次分清了”。

以下是项目设计预算，不是普适阈值，超过时先审查是否必要而不是机械截断：

| 项目 | r5 目标（保留 r4 的阅读基线） |
| --- | --- |
| 字体与字号 | 叙事麦圆体400与常规控件字体分工；24px 页面标题、19px 当前问题/正文/输入/主按钮、14px 节标签与必要辅助说明；重要操作不使用小字 |
| 首页系统文案 | 一个问题 + 一句首次发送说明，不含用户输入 |
| 普通 AI 当前回复 | 通常约70–140汉字，可更短；是否提问和展开以实际目的为依据，不凑问题、洞见或最低字数，不机械截断 |
| 用户请求的成品 | 最多三块，请求梳理的困扰通常约220–360汉字；不设最低字数，不默认“这次分清了”，关键经历与感受不能全部折叠，未知保持可见 |
| 高强调动作 | 每屏至多一个，位置稳定，名字就是实际动作 |
| 主线提交 | 直接开始，按需继续和自行收尾；没有固定轮数、必经成稿或保存。历史A样例四次模型调用/五次主提交只作有目的梳理的设计例，不是所有体验门槛 |
| 深层功能 | 旧版本地“先整理”、历史、编辑可发现；r5成稿请求应与零调用动作清楚区分，保存、配置与导出不占倾诉主线 |

### 两人形成性研究与五人无指导验收

先做2名形成性研究，再用5名未使用待验版本的新手验收；前2人不能抵作后5人。两组均尚未执行。两人研究可在全部历史模型内容评分完成前用明确标识的原型、回放或受控版本发现需求、问法和收尾负担，不据此放行AI内容或发布。固定回放用合成任务，不冒充对参与者临场私密表达的真实理解；响应方式和协助必须记入证据。

五人验收前须有 r5 范围内的同版本定向检查及真实链路证据，关闭丢字、无法停止、被迫保存、无视明确纠正、编造关键事实等阻断；不以等待全部历史选择样本或所有自选模型通过来无限推迟低风险方向发现。前2名新手逐人进行，出现阻断或两人都需操作指路时先修共同问题，再决定后3名。执行方式、观察字段和责任回流见 [beta-test-kit.md](beta-test-kit.md)。

五人只收到“请用一件你愿意谈的日常小事试试这个页面，随时可以停，不保存也可以”的任务，不预先教按钮或演示操作。以下分别计数，不互相抵消，也不是统计代表性或疗效结论：

1. **主线自主性**：至少4/5无需操作指路完成开始、继续及自己选择的收尾；主动不成稿、不保存并正常结束可以成功。约5秒入口观察、犹豫、反复阅读、误点、求助、放弃及被追问催促的位置逐项记录；“下一步点哪里”的帮助单独计一次。
2. **保存／找回功能**：独立保留至少4/5自愿完成保存并重新找到记录的证据。可以在主线结束后另行征得同意，用给定合成记录检查；区分自然保存和合成功能任务。自愿不保存既不记主线失败，也不证明保存能力；同一5人批次不足4份功能证据时保持未验证，不逼存私人内容，也不拿前2名形成性参与者补数。
3. **内容与被理解感**：按实际目的记录是否能继续说、是否得到具体回应，或是否能说出一项有依据的区分；片刻不强求洞见。自愿指出贴近或不像本人的一句话，允许“没有帮助”及不愿评价。记录即时主观体验，不宣称持续情绪改善。
4. **恢复与自主控制**：主线后可另行请求查找修改、返回和结束；旧“先整理”本地动作与r5明示成稿请求分别检验，不能靠省略恢复能力减少操作数。

客观行为、主观自述、源事实忠实、保存功能及整体内容质量分别出结论。操作顺畅、保存成功、模型评测数量或总体满意度都不能单独证明“被理解”或“已解决好麻烦”。观察默认不录音录像、不上传原始对话和私密正文；仅保留版本、响应方式、事件计数及许可范围内的去标识反馈。
