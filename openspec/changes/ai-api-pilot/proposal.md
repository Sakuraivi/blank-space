## Why

留白原型用固定问题收集原话，用户希望朋友无需配置模型 Key 即可体验个性化追问与可纠正的整理。首轮已选择 DeepSeek，测试总预算人民币 1 元以内，由平台所有者统一承担；真实 Key 尚未填写。

## What Changes

- 固定接入 `deepseek-flash` 非思考 JSON 模式，平台每轮组装场景规则，服务端持有凭据并校验候选。
- 使用 D1 原子调用账本：每次保守占用 ¥0.05，全批最多 18 次，共 ¥0.90，保留 ¥0.10 余量；失败、取消和未知结果不自动退回或重试。
- 增加主动选择的 AI 分支、明确 DeepSeek 传输同意和体验码准入，支持实际问题与答案关联、纠正、编辑确认、取消和原话回退。
- 增加受 Sites 身份保护的管理员 Key 设置/替换/删除入口。本轮供应商、模型和预算固定，不提供任意地址转发或访客自带 Key。
- 将手写前端源码迁至 `public/`，以 Vinext / Cloudflare Worker 提供同源 API 与 D1；`dist/` 作为构建输出。
- 保留现有 Sites 项目 ID 与公开受众配置；网站访问、管理员授权、模型调用同意分别处理。默认未配置 Key 的版本 2 已发布，待线上验收后由用户填写 Key 并完成真实小样本。
- 用户选择自定义域名 `blank.sakura.observer`；Sites 绑定、DNS、平台和证书状态已 active，浏览器 HTTPS 首页正常，无登录拦截；真实模型仍未启用。
