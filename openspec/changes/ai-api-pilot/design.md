## Context

留白已有三模式、六张原创卡片、编辑确认、本机保存和导出。原来的 `dist/` 手写静态源码已迁到 `public/`；当前使用 Vinext / Cloudflare Workers，提供同源 API、管理员页面和 D1 持久账本。既有 Sites 项目 ID 与访问受众保留。

用户已确定首家供应商 DeepSeek，测试总预算人民币 1 元以内。2026-10-30 核验的中文价格页显示 `deepseek-flash` 高峰缓存未命中输入 ¥2/百万 token、输出 ¥8/百万 token。采用非思考 JSON 模式，`max_tokens=1000`、完整请求 UTF-8 字节最多 12000、响应最多 128 KiB。每次按 ¥0.05 保守占用，18 次共 ¥0.90，保留 ¥0.10 余量。报价验证有效期至北京时间 2026-11-06 00:00，到期停用待复核。[价格来源](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

当前 78 项自动化测试通过，使用假凭据、假供应商响应及测试数据库。真实 Key 未填写，账号模型权限、真实内容质量和账单均待验证；本次生产发布尚未确认。

## Goals / Non-Goals

**Goals:** 管理员统一配置，体验者免配 Key；提供可纠正的短轮对话和整理；将调用授权、提示词、候选、状态和持久额度边界落实为可测试行为。

**Non-Goals:** 个人订阅公共代理；任意 URL 转发；本轮多供应商/任意模型选择；跨设备保存私人记录；以程序测试替代真实质量评测。

## Decisions

1. 固定第一条供应商路径。`ai/deepseek.mjs` 仅访问官方 Chat Completions 端点，禁止重定向，限制输入/输出并完整解析响应。关闭思考，使用 JSON 输出模式；成功停止后仍须候选校验。
2. 服务端重建上下文和规则。用户材料单独传入，问题与模型假设只是历史；用户回答和纠正才是可引用证据。卡牌元数据不作证据。模型不能确认、保存或控制状态迁移。
3. 实际问题与回答存为内存 `turns`，最多三个；`feedback` 最多六项，保存被评价假设、判定和最多 1000 字符的用户纠正。反馈随下一轮发送，不单独增加请求。旧 review 不作为新证据发送。
4. D1 `pilot_requests` 以一个 SQL 写入原子检查全批 18 次、每会话 5 次及并发 2 次，再预留调用；无生产内存回退。每次占用整数 50000 微元。客户端不能声明余额；刷新或换会话不重置全局额度。
5. 同一 requestId 不重复调用；复用 ID 但改变材料摘要或配置版本则拒绝。重复结果不从服务端正文缓存恢复，因为账本不存正文。取消、超时、无效结果可能已经计费，所以保留预留，不自动重试或跨服务商切换。
6. 服务端检查同源写请求、体验码、同意版本、配置版本和材料上限后才预留并调用。配置变化或价格到期时停止。若供应商返回用量超出输入/输出或预留假设，关闭 AI 待检查。
7. 管理页 `/admin.html` 通过 Sites 身份头授权。首次由 `LIUBAI_BOOTSTRAP_EMAIL` 指定站点所有者，随后绑定站点范围稳定用户 ID。该信任依赖 Sites dispatch，不是普通 Worker 可直接复用的身份方案。
8. API Key 使用 `LIUBAI_SECRET_KEY` 与随机 IV 做 AES-GCM 加密，密文存 D1；体验码只存摘要。后台不回传 Key。管理员保存配置不调用模型，删除 Key 关闭 AI，但不清空额度账本。
9. 前端默认本地模式。AI 入口要求体验码及明确同意将本次材料发送给 DeepSeek。任何更改、返回、结束、换会话或重新请求都会使旧响应失效。服务端等待 45 秒，浏览器等待 50 秒；取消请求与拒收旧结果分别落实。
10. AI 草稿只进入编辑确认页；已编辑草稿不能被迟到响应覆盖。失败保留输入，可原话整理或继续剩余本地问题。确认后保存使用字段白名单，不保存原始问答、反馈轨迹、请求状态或凭据。
11. 源码、构建和发布分离。`public/` 是手写网页，`app/` 与 `worker/` 是服务端，`db/` 与 `drizzle/` 描述 D1；`dist/` 是生成产物。现有站点先发布未配置 Key 的版本，真实小样本在用户完成配置后进行。

## Risks / Trade-offs

- [预算不是供应商账单保证] → 固定模型、价格复核期限、输入/输出上限及 0.10 元余量；真实请求后核对 usage 与账单，不把预留额当作实际消费。
- [公开站点被批量消耗] → AI 采用私下分发体验码，全局持久总数、会话和并发限制；会话限额不等于实名每人限额。
- [取消后上游仍可能执行] → 不退回占用、不自动重试，已接收文本无法通过清除浏览器撤回。
- [提示词或来源 ID 无法证明语义正确] → 单独评测纠正、第三方动机、卡牌、开心片刻、注入及迫近危险表达。
- [平台身份头信任被错误移植] → 生产仅经 Sites dispatch；其他部署需另行实现可信身份验证。
- [原话与模型过程泄漏到保存/日志] → 保存白名单、D1 仅元数据与摘要、受控错误码、前端转义；服务商的数据处理需明确告知。

## Migration Plan

实现已从静态结构迁到 Vinext / Worker + D1，保留页面、素材、站点 ID 与受众。自动测试已通过，完整 mock 浏览器流程、失败原话回退、取消慢请求后的迟到响应不覆盖均已验证；匿名管理页被拒绝，官方本地 mock 登录可进入表单，最终构建成功退出。

下一步发布默认未配置 Key 的版本，验证生产本地流程、状态接口及管理员拒绝匿名访问。再由用户填写真实 DeepSeek Key 和体验码，启用后以少量虚构材料完成连接、质量和用量核验，计入同一批 18 次限额。未配置、发布失败或验证未通过时不得把 AI 标记为可用或合格。
